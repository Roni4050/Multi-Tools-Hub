# Multi Tools Hub – 30+ Free Online Tools for Creators & Professionals

Explore 30+ free, client-side web tools crafted for creators, freelancers, self-publishers, and professionals. Edit images, manage PDFs, generate QR codes, calculate finance & mortgage metrics, and simplify daily tasks — 100% in your browser with zero server uploads.

---

## 🚀 Key Features

- **100% Client-Side Privacy**: All processing (PDF merge, image resizing, EXIF stripping, video trimming, audio normalization) runs locally in your browser using modern Web APIs, Web Workers, and WebAssembly. No files are ever uploaded to a remote server.
- **30 High-Utility Tools**:
  - **PDF Suite**: Merger, Splitter & Image Extractor, Page Organizer & Rotator, Compress & Flatten, PDF to JPG/PNG Converter, and Encrypt/Protect.
  - **Image & Design Tools**: Bulk WebP/PNG/JPG Converter, Bulk Image Resizer, Watermark & EXIF Metadata Scrubber, Color Palette Extractor, SVG Color Changer, and Aspect Ratio Calculator.
  - **Video & Creator Studio**: Safe-Zone Overlay Checker, YouTube/Social Thumbnail Previewer, Video Trimmer & Silence Cutter, Audio Normalizer & Voice Enhancer, Subtitle Editor (SRT/VTT), and Color LUT Previewer.
  - **Publishing & Documents**: KDP Bleed & Cover Size Calculator, Markdown to PDF Document Formatter, Resume/CV Privacy Redactor, Batch Watermark Stamper, and Multi-Format QR Code Generator.
  - **Daily Business & Productivity**: Tip & Bill Split Calculator, Loan & Mortgage Payment Calculator, Sales Tax & Discount Finder, Time Zone Meeting Planner, Pomodoro Focus Timer, Unit & Currency Converter, Strong Password Generator, Text Difference Checker, and Word & Character Counter.
- **Ultra-Fast & Responsive**: Built with Tailwind CSS typography, fluid widescreen layout, dark modern UI, tokenized instant search, and instant keyboard shortcuts (`Ctrl+K` / `/`).

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Roni4050/Multi-Tools-Hub.git
   cd Multi-Tools-Hub
   ```

2. **Start the local server**:
   ```bash
   node server.js
   ```

3. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)
